# Фотографии компании

Положите сюда свои снимки и укажите пути в `src/config/media.ts`.

Что снять (15 минут на телефон):
- `ploshadka.jpg` — общий план площадки с воротами и вывеской;
- `vesy.jpg` — весы с табло крупно;
- `transport.jpg` — ваши машины, желательно с логотипом на борту;
- `pogruzka.jpg` — момент погрузки на объекте;
- `sortirovka.jpg` — рассортированные кучи по видам металла.

Рекомендации: ширина 1600 px достаточно, снимайте днём, не используйте
фильтры. Next.js сам сожмёт файлы в WebP/AVIF при сборке.

Не кладите сюда изображения из интернета: за чужие фото в этой нише
регулярно приходят претензии, а стоковые кадры узнаются и снижают доверие.
