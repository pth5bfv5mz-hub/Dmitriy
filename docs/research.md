## 2. Формулы и методики по темам плана

Обозначения расшифрованы под каждой формулой. Все они рассчитаны на 2–4 действия — уровень СПО.

### 2.1. Логистический цикл (занятие 5)

**Длительность цикла выполнения заказа:**

    Т_ц = t₁ + t₂ + … + tₙ = Σ tᵢ

- `Т_ц` — длительность цикла выполнения заказа, дней (или часов)
- `tᵢ` — длительность i-го этапа цикла (приём заказа, комплектация, погрузка, перевозка, приёмка у клиента)
- `n` — число этапов

**Доля этапа в цикле:**

    dᵢ = tᵢ / Т_ц × 100 %

**Узкое место** — этап с максимальным `tᵢ` (или с максимальной долей `dᵢ`).

### 2.2. Эффективность и результативность, правило 7R (занятие 6)

**Эффективность** — соотношение результата и затрат:

    Э = Р / З

- `Р` — полученный результат (объём отгрузки, выручка, число заказов)
- `З` — затраты на его получение, руб.

**Результативность** — степень достижения цели:

    Рез = Ф / П × 100 %

- `Ф` — фактическое значение показателя
- `П` — плановое (целевое) значение

**Правило «7R»** (семь правил логистики) — качественный чек-лист, не формула. Нужный товар (right product) — нужного качества (right quality) — в нужном количестве (right quantity) — в нужное время (right time) — в нужное место (right place) — нужному потребителю (right customer) — с требуемыми затратами (right cost). Задание строится как проверка кейса по семи пунктам.

### 2.3. Логистические издержки (занятия 7–11)

**Совокупные логистические издержки:**

    С_общ = С_зак + С_тр + С_скл + С_зап + С_упр

- `С_зак` — затраты на закупочную деятельность (оформление, размещение заказов), руб.
- `С_тр` — транспортные затраты, руб.
- `С_скл` — затраты на складирование и грузопереработку, руб.
- `С_зап` — затраты на содержание запасов, руб.
- `С_упр` — управленческие (административно-логистические) затраты, руб.

**Доля логистических издержек в выручке:**

    d = С_общ / В × 100 %

- `В` — выручка от реализации за тот же период, руб.

**Логистические издержки на единицу продукции:**

    с_уд = С_общ / Q

- `Q` — объём реализации в натуральном выражении (т, шт., паллет)

**Постоянные и переменные затраты:**

    С_общ = FC + VC_уд × Q

- `FC` — постоянные затраты за период, руб. (аренда склада, оклады)
- `VC_уд` — переменные затраты на единицу, руб./ед. (топливо, сдельная оплата, упаковка)

**Критерий общих затрат (занятие 11)** — выбор варианта по минимуму суммы всех затрат:

    выбирается вариант с min ( С_тр + С_скл + С_зап + С_проч )

Смысл конфликта издержек (trade-off, занятие 10): по одной статье вариант дешевле, по другой — дороже; решение принимается только по итоговой сумме.

### 2.4. Запасы: затраты на содержание (занятие 13)

**Средний запас:**

    З_ср = (З_нач + З_кон) / 2

- `З_нач`, `З_кон` — запас на начало и на конец периода (руб. или ед.)

**Годовые затраты на содержание запаса:**

    С_сод = З_ср × i

- `i` — ставка (норма) содержания запаса, доля от стоимости запаса в год (включает хранение, страхование, потери, стоимость замороженных денег)

При равномерном расходе партии:

    С_сод = (q / 2) × Ц × i

- `q` — размер партии поставки, ед.
- `Ц` — цена единицы запаса, руб.

**Замороженные в запасе деньги** = `З_ср` в стоимостном выражении; стоимость их удержания = `З_ср × r`, где `r` — годовая ставка стоимости капитала, доля.

### 2.5. Оборачиваемость запасов (занятие 14)

**Коэффициент оборачиваемости (в оборотах):**

    К_об = В / З_ср          (или С_реал / З_ср)

- `В` — выручка (либо `С_реал` — себестоимость реализованной продукции) за период, руб.
- `З_ср` — средний запас за тот же период, руб.

> Методическое замечание: считать можно и по выручке, и по себестоимости. По себестоимости корректнее (числитель и знаменатель в одних ценах), по выручке — проще для студентов. **В курсе используем один способ и оговариваем его в каждой задаче.**

**Оборачиваемость в днях (период оборота):**

    Д_об = Т / К_об = З_ср × Т / В

- `Т` — число дней в периоде (30, 90, 360 — задаётся условием)

**Чтение результата:** рост `К_об` и снижение `Д_об` — запас крутится быстрее, деньги высвобождаются; падение `К_об` — затоваривание.

Источники: формулы `К_об = Себестоимость (выручка) / средняя стоимость запасов`, `З_ср = (начало + конец)/2`, `Д_об = средний запас / среднедневные продажи` — **[П]**.

### 2.6. Коэффициент закрепления, срок хранения, запасоёмкость (занятие 15)

**Коэффициент закрепления запаса** (обратный оборачиваемости):

    К_закр = З_ср / В = 1 / К_об

Показывает, сколько рублей запаса приходится на 1 рубль выручки.

**Средний срок хранения запаса:**

    t_хр = Т / К_об  = Д_об  (дней)

**Запасоёмкость:**

    Z = З_ср / В × 100 %

- по смыслу совпадает с `К_закр`, выраженным в процентах

> Это удобный дидактический ход для занятия 15: три «разных» показателя считаются из одной пары чисел (`З_ср` и `В`) и являются перевёрнутыми/пересчитанными версиями друг друга. Студент должен увидеть связь: `К_об × К_закр = 1`, `Д_об = Т × К_закр`.

### 2.7. ABC-анализ (занятия 16–17)

Порядок шагов:

1. Выбрать признак (годовой объём продаж в рублях, объём потребления).
2. Отсортировать позиции по убыванию признака.
3. Доля позиции: `dᵢ = Sᵢ / ΣS × 100 %`, где `Sᵢ` — значение признака по i-й позиции.
4. Нарастающий итог: `Dᵢ = d₁ + d₂ + … + dᵢ`.
5. Отнести к группам по границам нарастающего итога.

Типовые границы (задаются методикой предприятия, не жёсткая норма):

| Группа | Нарастающий итог | Смысл |
|--------|------------------|-------|
| A | до 80 % | немного позиций, основной вклад — жёсткий контроль |
| B | 80–95 % | средний вклад — обычный контроль |
| C | 95–100 % | много позиций, малый вклад — упрощённый контроль |

Основание — принцип Парето (примерно 20 % позиций дают около 80 % результата). Границы 80/95 — распространённая практика, **не норматив**; в задачах указывать их в условии.

### 2.8. XYZ-анализ (занятие 18)

**Среднее значение спроса:**

    x̄ = Σ xᵢ / n

- `xᵢ` — спрос (продажи) в i-м периоде, ед.
- `n` — число периодов

**Среднее квадратическое отклонение:**

    σ = √( Σ (xᵢ − x̄)² / n )

**Коэффициент вариации:**

    v = σ / x̄ × 100 %

Границы групп **[П]**:

| Группа | Коэффициент вариации | Спрос |
|--------|----------------------|-------|
| X | 0–10 % | устойчивый, хорошо прогнозируется |
| Y | 10–25 % | колеблющийся |
| Z | свыше 25 % | нерегулярный, плохо прогнозируется |

В Excel: `=СТАНДОТКЛОНП(диапазон)/СРЗНАЧ(диапазон)` **[П]**.

> Для колледжа: 3–4 периода и «круглые» числа, чтобы σ считалась в столбик без калькулятора функций. Границы 10 % / 25 % — отраслевая практика, а не норматив, и в отдельных отраслях группу Y расширяют — это оговаривается в условии задачи.

### 2.10. Показатели склада (занятия 21–23)

**Грузооборот склада** (объём работы за период):

    Г = Г_прих + Г_расх

- `Г_прих` — количество груза, поступившего на склад за период, т
- `Г_расх` — количество груза, отпущенного со склада, т

Суточный грузооборот: `Г_сут = Г_год / Т`, где `Т` — число рабочих дней в году.

**Коэффициент грузопереработки** (коэффициент перегрузки) — среднее число операций, выполненных с каждой тонной груза:

    К_гп = Г_то / Г

- `Г_то` — объём грузопереработки, тонно-операций (сумма всех перемещений/перевалок груза внутри склада)
- `Г` — грузооборот склада, т

Чем ниже `К_гп`, тем рациональнее организованы работы **[П]**.

**Удельный грузооборот:**

    Г_уд = Г / S

- `S` — площадь склада, м² **[П]**

**Коэффициент использования площади:**

    К_S = S_пол / S_общ        (или × 100 %)

- `S_пол` — полезная (грузовая) площадь, занятая хранением, м²
- `S_общ` — общая площадь склада, м²

**Коэффициент использования объёма:**

    К_V = V_пол / V_общ

- `V_пол` — полезный объём зоны хранения, м³
- `V_общ` — общий объём склада, м³

**Грузонапряжённость:**

    g = Г / S_пол   (т/м²)

**Производительность труда складского работника:**

    П = Г / Ч

- `Ч` — среднесписочная численность складских работников, чел.
- за смену: `П_см = Г_см / Ч_см`

**Себестоимость переработки одной тонны:**

    с₁ = С_скл / Г

- `С_скл` — все затраты склада за период, руб.
- `Г` — грузооборот за тот же период, т

### 2.11. Показатели транспорта (занятия 24–26)

**Составляющие пробега:**

    L_общ = L_гр + L_х + L_н

- `L_общ` — общий пробег, км
- `L_гр` — гружёный (рабочий) пробег, км
- `L_х` — холостой (порожний) пробег между точками, км
- `L_н` — нулевой пробег (выезд из парка и возврат), км

**Коэффициент использования пробега:**

    β = L_гр / L_общ

Формула подтверждена **[П]** (отношение суммы рабочих пробегов к сумме общих пробегов).

**Статический коэффициент использования грузоподъёмности:**

    γ_с = q_ф / q_н

- `q_ф` — фактически перевезённая масса груза за ездку, т
- `q_н` — номинальная грузоподъёмность автомобиля, т

**Динамический коэффициент использования грузоподъёмности:**

    γ_д = P_ф / P_возм

- `P_ф` — фактически выполненный грузооборот, ткм
- `P_возм` — грузооборот, возможный при полном использовании грузоподъёмности на всём гружёном пробеге, ткм (`P_возм = q_н × L_гр`)

Подтверждено **[П]**: «отношение числа фактически выполненных тонно-километров к числу тонно-километров, которые могли быть выполнены при полном использовании грузоподъёмности».

**Коэффициент технической готовности парка:**

    α_т = Д_тг / Д_к

- `Д_тг` — автомобиле-дни в технически исправном состоянии
- `Д_к` — календарные автомобиле-дни за период

**Коэффициент выпуска на линию:**

    α_в = Д_э / Д_к

- `Д_э` — автомобиле-дни в эксплуатации

**Транспортная работа:**

    P = Q × L_гр

- `Q` — масса перевезённого груза, т
- результат — ткм

**Себестоимость рейса:**

    С_рейса = С_топл + С_зп + С_ам + С_то + С_накл

- `С_топл` — затраты на топливо: `С_топл = (Н × L_общ / 100) × Ц_топл`, где `Н` — норма расхода, л/100 км; `Ц_топл` — цена литра, руб.
- `С_зп` — оплата труда водителя с отчислениями, руб.
- `С_ам` — амортизация за рейс, руб.
- `С_то` — техобслуживание, шины, ремонт, руб.
- `С_накл` — накладные (общехозяйственные) расходы, руб.

**Себестоимость тонно-километра:**

    с_ткм = С_рейса / P

**Себестоимость одного километра:**

    с_км = С_рейса / L_общ

**Тариф:**

    Т = с × (1 + R)

- `с` — себестоимость единицы работы (ткм или км), руб.
- `R` — норма рентабельности (прибыли), доля

### 2.12. Выбор перевозчика и рейтинг поставщика (занятия 27, 29)

**Метод рейтинговых (балльных) оценок:**

    R = Σ ( wᵢ × bᵢ )

- `wᵢ` — вес (значимость) i-го критерия, доля; `Σ wᵢ = 1`
- `bᵢ` — балл поставщика/перевозчика по i-му критерию (например, шкала 1–10)
- `R` — итоговый рейтинг; выбирается вариант с наибольшим `R`

Порядок: выбрать критерии → задать веса экспертно → выставить баллы → перемножить и просуммировать → сравнить **[П]**.

Типовые критерии **[П]**: надёжность доставки, гарантии качества, производственные мощности, цены, местоположение, технический потенциал, финансовое положение, послепродажный сервис.

> Важно объяснить студентам: если критерий «чем меньше, тем лучше» (цена, срок), балл выставляется в перевёрнутой шкале, иначе рейтинг получится бессмысленным. Это типичная ошибка на такой задаче.

### 2.13. Оценка закупочной деятельности (занятие 28)

**Доля брака в поставках:**

    d_бр = Q_бр / Q_пост × 100 %

- `Q_бр` — количество забракованного (возвращённого) товара, ед. или т
- `Q_пост` — общее количество поступившего товара

**Доля срывов срока поставки:**

    d_ср = N_ср / N_общ × 100 %

- `N_ср` — число поставок с нарушением срока
- `N_общ` — общее число поставок

**Своевременность поставок:** `d_св = 100 % − d_ср`

**Экономия (перерасход) при закупке:**

    Э = (Ц_пл − Ц_ф) × Q

- `Ц_пл` — плановая (базовая) цена единицы, руб.
- `Ц_ф` — фактическая цена закупки, руб.
- `Q` — закупленное количество, ед.
- `Э > 0` — экономия, `Э < 0` — перерасход

### 2.14. Уровень логистического обслуживания (занятие 30)

    η = m / M × 100 %

- `η` — уровень логистического сервиса, %
- `m` — количественная оценка фактически оказываемого объёма логистического сервиса
- `M` — количественная оценка теоретически возможного объёма логистического сервиса

Формула и обозначения подтверждены **[П]** (Гаджинский А. М.).

**Вариант по номенклатуре** (для занятия 30 — самый удобный):

    η = n / N × 100 %

- `n` — число позиций номенклатуры, фактически поставляемых (доступных клиенту)
- `N` — общее число позиций, которые в принципе может запросить клиент

**Вариант по времени выполнения услуг:**

    η = Σ tᵢ / Σ Tⱼ × 100 %

- `tᵢ` — время на выполнение i-й фактически оказываемой услуги
- `Tⱼ` — время на выполнение j-й услуги из теоретически возможного перечня

### 2.15. Показатели качества обслуживания: OTIF и полнота (занятие 31)

**OTIF (On Time In Full) — вовремя и в полном объёме:**

    OTIF = N_отиф / N_общ × 100 %

- `N_отиф` — число заказов, выполненных одновременно и в срок, и полностью
- `N_общ` — общее число заказов за период

Подтверждено **[П]**: заказ засчитывается только при выполнении **обоих** условий; ориентиры отрасли — 85–95 % «хорошо», 95–98 % «отлично» (это рыночные ориентиры, а не норматив).

**OTD (On Time Delivery) — своевременность:**

    OTD = N_срок / N_общ × 100 %

**Полнота заказа по заказам (In Full):**

    IF = N_полн / N_общ × 100 %

**Полнота заказа по количеству (Fill Rate):**

    FR = Q_отгр / Q_зак × 100 %

- `Q_отгр` — фактически отгруженное количество, ед.
- `Q_зак` — заказанное количество, ед.

**Среднее время выполнения заказа:**

    T̄ = Σ (дата отгрузки − дата заказа) / N_общ   (дней)

> Ключевая мысль занятия: OTIF всегда **не выше** и обычно **ниже** и OTD, и IF, потому что требует выполнения обоих условий сразу. Это хорошо проверяется задачей на журнале из 10–12 заказов: студент считает три показателя и видит `OTIF ≤ min(OTD, IF)`.

### 2.16. Затраты и уровень сервиса (занятие 32)

Затраты на сервис растут быстрее, чем сам уровень сервиса (после ~70 % — резко), а потери от недостаточного сервиса, наоборот, падают. Оптимум — минимум суммы:

    С_итог(η) = С_серв(η) + С_потерь(η) → min

- `С_серв(η)` — затраты на обеспечение уровня сервиса η, руб.
- `С_потерь(η)` — потери от упущенных продаж и от ухода клиентов при этом уровне, руб.

Практический вид задания: таблица из 4–5 вариантов уровня сервиса с готовыми парами затрат — студент складывает столбцы и выбирает строку с минимумом. Второй способ подачи — по прибыли: `П(η) = В(η) − С_серв(η) → max`.

### 2.17. KPI логистики (занятия 33–34)

Формул как таковых нет — работа с требованиями и структурой. Группы показателей, встречающиеся в практике **[Ч]**:

- **общие логистические издержки** — `С_общ`, доля в выручке, издержки на единицу;
- **качество логистического сервиса** — OTIF, OTD, fill rate, уровень обслуживания, доля рекламаций;
- **длительность логистических циклов** — `Т_ц` цикла выполнения заказа, время обработки заказа;
- **производительность** — грузооборот на работника, ткм на автомобиль, заказов на комплектовщика;
- **использование ресурсов / возврат на вложения** — `β`, `γ_д`, `К_S`, оборачиваемость запасов, срок окупаемости.

Требования к KPI (SMART) и типичные ошибки при постановке:

| Требование | Плохой KPI | Хороший KPI |
|------------|-----------|-------------|
| Измеримость | «улучшить работу склада» | «доля ошибок при комплектации ≤ 0,5 %» |
| Управляемость | «выручка компании» для кладовщика | «время комплектации заказа ≤ 25 мин» |
| Одна цель — один показатель | «снизить затраты и повысить сервис» | два отдельных KPI с целевыми значениями |
| Наличие целевого значения | «повысить OTIF» | «OTIF ≥ 95 % к концу квартала» |
| Отсутствие конфликта | «минимум запасов» + «отсутствие дефицита» | целевая оборачиваемость при уровне сервиса ≥ 97 % |

Каскадирование: цель компании → цель логистики → KPI подразделения → KPI сотрудника.

### 2.18. Оценка инвестиций в логистику (занятие 35)

**Простой срок окупаемости:**

    Т_ок = К / Э

- `К` — сумма вложений (капитальных затрат), руб.
- `Э` — годовая экономия (или годовой дополнительный доход) от вложения, руб./год
- `Т_ок` — срок окупаемости, лет

**Годовая экономия:**

    Э = С_до − С_после

- `С_до` — годовые затраты до внедрения, руб.
- `С_после` — годовые затраты после внедрения (включая новые расходы на обслуживание техники), руб.

**Рентабельность вложения:**

    R_К = Э / К × 100 %

> Для колледжа берём **простой** срок окупаемости без дисконтирования. Дисконтирование, NPV и IRR из этого курса исключаем — это уровень вуза и не заявлено в плане.

### 2.19. Анализ отклонений «план — факт» (занятие 39)

**Абсолютное отклонение:**

    ΔА = Ф − П

**Относительное отклонение:**

    Δ% = (Ф − П) / П × 100 %

**Процент выполнения плана:**

    В% = Ф / П × 100 %

- `Ф` — фактическое значение показателя
- `П` — плановое значение

Формулы подтверждены **[П]**.

**Чтение знака** — ключевой момент занятия: для показателей-результатов (выручка, грузооборот, OTIF) `ΔА > 0` — благоприятно; для показателей-затрат (издержки, порожний пробег, срок доставки) `ΔА > 0` — неблагоприятно. Отклонения свыше 20 % в практике считают критическими и требуют разбора причин **[Ч]** (это управленческая практика, а не норматив — так и подавать студентам).

### 2.20. Аутсорсинг: «делать или покупать» (занятие 40)

**Затраты при выполнении своими силами:**

    С_свои = FC + VC_уд × Q

- `FC` — постоянные затраты (аренда, оклады, амортизация техники), руб./период
- `VC_уд` — переменные затраты на единицу, руб./ед.
- `Q` — объём работы за период, ед. (т, паллет, рейсов)

**Затраты при передаче подрядчику:**

    С_подр = Т_уд × Q

- `Т_уд` — тариф подрядчика за единицу, руб./ед.

**Решение:** передавать подрядчику, если `С_подр < С_свои`.

**Объём безразличия (точка равных затрат):**

    Q* = FC / (Т_уд − VC_уд)

При `Q < Q*` дешевле подрядчик, при `Q > Q*` — свои силы (при `Т_уд > VC_уд`).

Нефинансовые критерии решения (для кейсовой части): критичность функции для бизнеса, наличие компетенций внутри, риск потери контроля над качеством, зависимость от одного подрядчика, конфиденциальность данных, гибкость при росте объёмов.

## 4. Методические решения, принятые по итогам исследования

1. **Оборачиваемость считаем по выручке**, база оговаривается в каждой задаче. Так проще для группы со слабой базой; вариант «по себестоимости» упоминаем на занятии 14 одной строкой.
2. **Границы ABC (80/95) и XYZ (10 %/25 %) даём как принятую практику, а не норматив** — во всех задачах они прописаны в условии. Это защищает от ошибки «студент выучил границы как закон».
3. **Период Т в формулах оборачиваемости всегда задан в условии** (30, 90, 360 дней) — не оставляем на догадку.
4. **Срок окупаемости — только простой**, без дисконтирования (NPV/IRR за рамками плана и уровня).
5. **Матаппарат ограничен**: среднее, доля, процент, среднее квадратическое отклонение (для XYZ, в столбик по 3–4 периодам), взвешенная сумма (рейтинг). Теории массового обслуживания, оптимизации, эконометрики в курсе нет.
6. **Числа в задачах — учебные**, кратные и «круглые», результат должен получаться в 2–4 действия. В каждом документе ставится помета «Данные условные».
7. **Названия компаний в кейсах — обезличенные** («ООО „Складсервис“ — условное предприятие»), реальные компании и их показатели не используются.
8. **Занятия 16–19 и 38** проектируем в двух вариантах объёма данных: 15 позиций для Excel, 8–10 позиций для расчёта вручную — по пункту 2 раздела «Что стоит проверить» в плане.

## 5. Замечания к плану (по вашему требованию — сообщаю, сам не правлю)

Расчёт часов по плану **сходится полностью**, расхождений нет:

Нумерация сплошная 1…43, пропусков и дублей нет.

**Три момента, которые стоит решить до этапа 2** (это не ошибки, а неоднозначности):

1. **Занятия 1 и 43 — по 1 часу.** При правиле «1 пара = 2 академических часа» это половина пары. В сумме по семестрам всё сходится (39 и 45 — оба нечётные, и одночасовое занятие как раз выравнивает баланс), но структура «40–50 мин теория + практика» на 45-минутное занятие не ложится. Предлагаю: **занятие 1** — техкарта на 45 минут (краткое введение + мини-опрос, без презентации на 14 слайдов, 8–10 слайдов); **занятие 43** — консультация без презентации и без практического задания, только техкарта и лист вопросов. Подтвердите или скажите иначе.

2. **Занятие 43 без задания.** В плане в графе «Задание на занятии» стоит «—». Значит комплект для занятия 43 будет из двух файлов (техкарта + лист экзаменационных вопросов), без .pptx и без практической работы. Проверка «у каждого занятия есть все файлы комплекта» для занятия 43 будет ослаблена — заложу это в правила сборки как явное исключение.

3. **Занятие 18 «XYZ-анализ»** — в исходном PDF название темы разорвано вёрсткой («Коэффициент вариации, / 18 2 XYZ-анализ устойчивость спроса…»). Я прочитал это так: **тема — «XYZ-анализ»**, теоретический блок — «Коэффициент вариации, устойчивость спроса, группы X, Y, Z». Если в вашем оригинале тема названа иначе (например, «Коэффициент вариации. XYZ-анализ») — скажите, поправлю `docs/plan.md`.
