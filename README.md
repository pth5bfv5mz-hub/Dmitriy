# Сайт приёма металлолома

Коммерческий сайт под трафик из Яндекс Директа: главная страница + 14 посадочных
страниц под рекламные группы. Next.js 16 (App Router), TypeScript, Tailwind CSS 4.
Все страницы статические, интерактив — только там, где он нужен для заявки.

Исследование рынка и разбор конкурентов, на которых построена структура, —
в [COMPETITOR_ANALYSIS.md](./COMPETITOR_ANALYSIS.md).

---

## Быстрый старт

```bash
npm install
npm run dev        # разработка, http://localhost:3000
npm run build      # production-сборка
npm start          # запуск собранной версии
npm run typecheck  # проверка типов
```

## ⚠️ Что обязательно сделать перед запуском рекламы

Сайт работает «из коробки», но с временными данными. Пока эти пункты не закрыты,
рекламу включать нельзя — бюджет уйдёт в никуда.

| # | Что | Где | Почему критично |
|---|-----|-----|-----------------|
| 1 | Реальные цены и дата прайса | `src/config/prices.ts` | Сейчас там рыночный ориентир по конкурентам, а не ваш прайс |
| 2 | Телефон, адрес, координаты, режим работы | `src/config/company.ts` | Заглушки `+7 (495) 000-00-00` и «ул. Примерная» |
| 3 | Подключить приём заявок | переменная `LEAD_WEBHOOK_URL` | Без неё форма честно говорит «приём заявок не подключён» и не принимает лиды |
| 4 | ID Яндекс.Метрики + завести цели | `src/config/company.ts` → `analytics` | Без целей Директ не сможет оптимизироваться по конверсиям |
| 5 | Домен сайта | `src/config/company.ts` → `site.url` | Иначе canonical, sitemap и OG указывают на `example.ru` |
| 6 | Свои фотографии площадки | `/public/photos/` + `src/config/media.ts` | Сейчас аккуратные заглушки. Свои фото конвертируют лучше любого стока |
| 7 | Реквизиты и номер лицензии | `src/config/company.ts` → `legal` | Пустые поля скрываются автоматически. **Не выдумывать** |
| 8 | Реальные зоны выезда | `src/config/company.ts` → `serviceAreas` | Не заявляйте территории, где не работаете |
| 9 | Цифры доверия (стаж, автопарк) | `src/config/company.ts` → `stats` | Пустые значения скрывают блок. Заполнять **только правдой** |

## Где что менять

Вся редактируемая информация вынесена в `src/config/`. Трогать компоненты не нужно.

```
src/config/
├── company.ts    ← телефон, адрес, город, режим работы, реквизиты,
│                    условия вывоза, зоны выезда, ID аналитики, домен
├── prices.ts     ← ВСЕ ЦЕНЫ. Категории, сорта, вилки, дата прайса,
│                    блок «от чего зависит цена»
├── landings.ts   ← посадочные страницы под группы Директа
├── faq.ts        ← вопросы и ответы
├── reviews.ts    ← отзывы (пуст: фальшивые не публикуем)
└── media.ts      ← пути к фотографиям
```

### Поменять цены

Только `src/config/prices.ts`. Оттуда цифры расходятся в таблицу прайса, карточки
категорий, калькулятор, заголовки посадочных страниц, метатеги и микроразметку.
Не забудьте обновить `priceUpdatedAt` — дата показывается рядом с таблицей.

### Поменять город

`src/config/company.ts` → `city`. Указываются три падежа, потому что по-русски
нужно и «Приём металлолома в Москве», и «по Москве и области». Тексты в конфигах
используют плейсхолдеры `{{city}}`, `{{cityPrep}}`, `{{phone}}` — они подставляются
автоматически (`src/lib/tokens.ts`).

### Добавить посадочную страницу под новую группу Директа

Добавьте объект в массив `landings` в `src/config/landings.ts`. Роут, метатеги,
микроразметка, `sitemap.xml` и перелинковка подхватятся сами.

> Не создавайте страницы ради ключевых слов. Страница нужна тогда, когда у группы
> свой оффер и своя цена — иначе она только размывает бюджет.

## Приём заявок

Формы не знают, куда уходит заявка, — они вызывают `submitLead()`
(`src/lib/leads.ts`), а обработчик `src/app/api/lead/route.ts` пересылает её дальше.

Задайте переменную окружения:

```bash
LEAD_WEBHOOK_URL=https://your-crm-or-bot.example/hook
```

Подойдёт что угодно, что принимает `multipart/form-data`: Telegram-бот, amoCRM,
Битрикс24, Make/n8n, свой обработчик на почту. Фотографии металла пересылаются
вместе с заявкой.

**Пока переменная не задана**, форма показывает честную ошибку с предложением
позвонить, а заявка пишется в лог сервера. Это сделано намеренно: показывать
«Спасибо, заявка принята», когда заявка никуда не ушла, — самый дорогой способ
потерять клиента и не узнать об этом.

Что уже есть в форме: состояния загрузки/успеха/ошибки с повторной отправкой,
валидация телефона, ловушка для ботов, ограничение на размер и тип фото,
чекбокс согласия на обработку персональных данных.

## Аналитика: цели для Яндекс.Метрики

Впишите ID счётчика в `src/config/company.ts` → `analytics.yandexMetrikaId`
и создайте в Метрике цели типа **JavaScript-событие** с такими идентификаторами:

| Идентификатор | Что означает |
|---|---|
| `phone_click` | Клик по номеру телефона |
| `whatsapp_click` | Переход в WhatsApp |
| `telegram_click` | Переход в Telegram |
| `form_submit` | Успешная отправка заявки |
| `pickup_order` | Заявка с заказом вывоза |
| `photo_attached` | Клиент приложил фото металла |
| `calculator_used` | Использован калькулятор |
| `calculator_to_form` | Переход из калькулятора в форму |
| `prices_viewed` | Просмотр полного прайса |
| `route_click` | Построение маршрута до площадки |

Ключевые для оптимизации кампаний: `phone_click`, `form_submit`, `pickup_order`.
Список целей задан в `src/lib/analytics.ts`.

## SEO

Настроено: `title`/`description` на каждой странице, единственный H1, `canonical`,
Open Graph с картинкой, favicon, `robots.txt` и `sitemap.xml` (генерируются из
конфига), микроразметка `LocalBusiness`, `FAQPage`, `Service` + `AggregateOffer`
с ценами и `BreadcrumbList`.

Разметка `Product` и `AggregateRating` сознательно не используется: мы не продаём
товар и у нас нет собранных оценок. Разметка, не соответствующая содержимому, ведёт
к санкциям, а не к красивому сниппету.

## Производительность

Замеры production-сборки (главная, мобильный вьюпорт):

| Метрика | Значение |
|---|---|
| HTML главной (со сжатием) | ~50 КБ |
| CSS (со сжатием) | ~6 КБ |
| FCP | ~150 мс |
| Запросов при загрузке | 15 |
| DOM-узлов | ~1650 |

Как это достигнуто: первый экран без изображений (фактуры — на CSS, иконки и
визуальные метки металлов — инлайновый SVG), FAQ на нативных `<details>` без
JavaScript, карта в `iframe` с `loading="lazy"`, счётчик Метрики через
`afterInteractive`, клиентские компоненты только там, где нужен интерактив
(форма, калькулятор, меню, панель CTA).

Когда добавите свои фотографии — Next сам сожмёт их в WebP/AVIF.

## Принципы, заложенные в сайт

Это не украшательства, а следствия разбора конкурентов — подробности в
`COMPETITOR_ANALYSIS.md`.

1. **Цена вилкой, а не «максималкой».** Конкуренты пишут «медь до 833 ₽/кг»
   и получают отказы на площадке. Мы показываем диапазон и объясняем сортность:
   меньше пустых звонков, дешевле лид.
2. **Фото — основной способ оценки.** Главный стопор заявки: «я не знаю, что у
   меня за металл и сколько он весит». Фотография это снимает.
3. **Взвешивание вынесено в отдельный блок.** Главный страх сдатчика — обвес,
   и он должен быть проговорён вслух.
4. **Ни одной выдуманной цифры.** Отзывы, стаж, лицензия, автопарк — либо
   настоящие, либо блок не показывается.
5. **Мобильный приоритет.** Фиксированная панель «Позвонить / Узнать цену»,
   прайс карточками вместо уезжающей таблицы, два обязательных поля в форме.
