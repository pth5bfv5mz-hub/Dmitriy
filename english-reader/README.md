# English Reader — чтение на английском (B1)

Веб-приложение для изучения английского на коротких текстах: читаете историю или эссе
на 300–380 слов уровня B1 со словарём по клику, проходите тест на понимание,
пересказываете своими словами и отвечаете на вопросы по теме.

**Работает бесплатно и офлайн.** В приложение встроены 30 текстов в восьми жанрах
(около 9300 слов для чтения) и словарь на 1577 статей: ключ, интернет и оплата
не нужны ни для чего из этого.

Ключ Anthropic (модель **claude-sonnet-4-6**) — необязательное дополнение. Он включает
генерацию новых текстов на любую тему, перевод слов, которых нет в словаре, проверку
пересказа с разбором ошибок и живой диалог с собеседником.

## Как открыть на телефоне (GitHub Pages, бесплатно)

У репозитория может быть только один сайт на GitHub Pages, а приложений в нём два.
Поэтому `npm run build:pages` собирает оба в одну папку `docs/`:

```
docs/          тренажёр слов (vocab-trainer) — адрес не меняется
docs/reader/   читалка English Reader
```

Тренажёр копируется готовой сборкой из `vocab-trainer/docs`, его исходники не трогаются:
он собран с относительными путями и одинаково работает и в корне, и из подпапки.

Включается один раз в настройках репозитория:

**Settings → Pages → Source: «Deploy from a branch» → Branch:
`claude/english-learning-app-b1-ek7itf`, папка `/docs` → Save.**

После этого:

- <https://pth5bfv5mz-hub.github.io/Dmitriy/> — тренажёр слов, как и раньше;
- <https://pth5bfv5mz-hub.github.io/Dmitriy/reader/> — читалка.

Читалка работает офлайн: тексты и словарь встроены, service worker сохраняет саму
страницу. Ставится на домашний экран («Поделиться» → «На экран Домой»), иконка
генерируется скриптом `npm run icons`.

Обновление сборки после изменений в коде:

```bash
cd english-reader
npm run build:pages
cd .. && git add docs && git commit -m "Обновить сборку" && git push
```

## Второй вариант: свой сервер (Render)

Нужен, если ключ не должен попадать в браузер: тогда он лежит на сервере,
а браузер общается только со своим сервером. В корне репозитория лежит `render.yaml`,
Render читает его сам:
1. Зайти на [render.com](https://render.com) → **Get Started** → войти через GitHub.
2. **Add new** → **Blueprint** → выбрать этот репозиторий → ветка
   `claude/english-learning-app-b1-ek7itf` → **Connect**.
3. Render покажет поле `ANTHROPIC_API_KEY` — вставить туда ключ с
   [console.anthropic.com](https://console.anthropic.com) → **Apply**.
4. Через 3–5 минут сервис получит постоянный адрес вида
   `https://english-reader-xxxx.onrender.com`.

Особенность бесплатного тарифа: если сайтом никто не пользуется 15 минут, сервер
засыпает, и первое открытие после паузы занимает около минуты. Дальше всё быстро.
Тексты при этом не теряются — они хранятся в браузере, а не на сервере.

Приложение само определяет, где оно работает: если рядом есть сервер — ключ берётся
с сервера и в браузер не попадает; если сервера нет (GitHub Pages) — спрашивается у вас.

## Быстрый старт

```bash
cd english-reader
npm install
cp .env.example .env      # и вписать свой ANTHROPIC_API_KEY
npm run dev
```

Откроется два процесса: backend на `http://localhost:8787` и фронтенд на
`http://localhost:5173` — заходить нужно на **5173**.

Ключ берётся из переменной окружения `ANTHROPIC_API_KEY` (файл `.env` читается автоматически).
Без ключа приложение запустится, но покажет предупреждение и не сможет генерировать тексты.

Продакшен-вариант одной командой: `npm run build && npm start` — тогда Express сам раздаёт
собранный фронтенд на `http://localhost:8787`.

## Жанры

Текст можно заказать в одном из жанров или нажать «Удиви меня» — тогда жанр и тему выберет ИИ:

| | Жанр | О чём |
|---|---|---|
| 🌱 | Мотивация | короткое эссе о жизни и привычках — формат постов вроде @english.read |
| ☕ | Из жизни | бытовая история: переезд, отношения, работа, семья |
| 🕯️ | Ужастик | крипи-рассказ с финалом, который переосмысляет начало |
| ⏱️ | Триллер | саспенс: время идёт, что-то вот-вот случится |
| 🔎 | Детектив | мини-загадка, все улики даны честно |
| 🔬 | Научпоп | одно любопытное явление простым языком |
| 🛰️ | Фантастика | одна идея «а что если» в близком будущем |
| 🌀 | Странное | магический реализм: обычный мир с одной странностью |

Тему можно вписать свою (по-русски или по-английски), выбрать из подсказок или оставить
поле пустым — тогда тема берётся случайная из пула жанра.

## Иллюстрации

Вместе с текстом Claude пишет описание сцены для картинки, а рисует её бесплатный сервис
[pollinations.ai](https://pollinations.ai) — по ссылке, без ключа и регистрации. Запрос уходит
из браузера читателя, сервер приложения в этом не участвует и денег это не стоит.

У каждого жанра свой визуальный стиль (кинокадр для ужастика, документальное фото для бытовых
историй, минималистичная схема для научпопа). Картинка привязана к тексту и не меняется при
повторном открытии. Если сервис не ответил, блок с картинкой просто не показывается —
на чтение это никак не влияет. Отключается галочкой «Иллюстрация к тексту» на главной.

## Как устроен маршрут по тексту

1. **Чтение** — 4–5 абзацев по 65–95 слов, фраза-крючок и финальная мысль выделены жирным.
   Каждое значимое слово кликабельно. Перевод даётся **в контексте предложения**,
   а не словарной статьёй. Служебные слова (артикли, предлоги, местоимения) не кликаются,
   чтобы не мешать чтению. Просмотренные слова подсвечиваются и собираются в список внизу.
2. **Тест** — 4 вопроса с вариантами ответов, генерируются вместе с текстом. После проверки
   видно верный ответ и объяснение по-русски.
3. **Пересказ** — вы пишете краткий пересказ по-английски, ИИ даёт оценку понимания (1–10),
   что понято верно, что упущено, и разбор языковых ошибок с исправлениями.
4. **Диалог** — свободный разговор о тексте: ИИ задаёт открытые вопросы, мягко поправляет
   явные ошибки коротко и по ходу. В конце — сводка: что получилось, что подтянуть,
   слова на повторение.

Переключение между этапами — вкладками или `Alt + ←/→`. Прогресс сохраняется автоматически,
в библиотеке видно статус каждого текста (не начат / читаю / тест пройден / диалог завершён)
и блок «Продолжить».

## Структура

```
docs/                 собранный сайт для GitHub Pages (в репозитории)
english-reader/
├─ shared/            общее для сервера и браузера
│  ├─ prompts.js      все промпты, включая правила уровня B1
│  └─ genres.js       каталог жанров, стили картинок, пул тем
├─ server/
│  ├─ index.js        HTTP-маршруты (Express), сервер без состояния
│  └─ claude.js       клиент Anthropic на стороне сервера
└─ src/
   ├─ App.jsx           каркас, определение режима работы
   ├─ api.js            один вызов → сервер или напрямую в Anthropic
   ├─ lib/anthropic.js  прямые запросы из браузера + хранение ключа
   ├─ lib/direct.js     логика генерации без сервера
   ├─ lib/library.js    хранение библиотеки в localStorage
   ├─ lib/image.js      ссылка на иллюстрацию
   ├─ lib/text.js       токенизация текста, служебные слова
   └─ components/       KeyGate, Library, TextWorkspace, Reader, Quiz, Retelling, Chat
```

**Где лежат данные.** Библиотека, словарь, результаты тестов и переписка хранятся
в `localStorage` браузера. Сервер не хранит ничего — он только ходит в Anthropic API.
Благодаря этому приложение переживает любые перезапуски на бесплатном хостинге,
где файловая система стирается. Обратная сторона: на каждом устройстве своя
библиотека. Чтобы начать с чистого листа, достаточно очистить данные сайта в браузере.

## Про уровень B1

Промпты ограничивают язык примерно 3000 наиболее частотных семейств слов и грамматикой,
типичной для graded readers уровня B1: простые времена, present perfect, первый и второй
кондишен, пассив и косвенная речь дозированно, предложения в 8–16 слов. Отдельный блок
правил отвечает за качество короткой формы: один эпизод, конкретные детали вместо
абстракций, финал, который даёт читателю что-то унести с собой. Объём проверяется на сервере:
если модель прислала меньше 280 слов, запрос автоматически повторяется с указанием переписать длиннее.

## Стоимость и приватность

Каждое действие — один запрос к Anthropic API, оплачивается по вашему ключу.
В варианте с GitHub Pages ключ хранится в `localStorage` браузера и уходит только
на `api.anthropic.com` (заголовок `anthropic-dangerous-direct-browser-access`).
Он не попадает ни в репозиторий, ни в адрес страницы; отозвать его можно в консоли
Anthropic. Кому такая модель не подходит — второй вариант с сервером держит ключ
на сервере.
Клик по слову кэшируется: повторный клик по тому же слову в том же предложении
берётся из памяти браузера и нового запроса не делает.
