# Слова — тренажёр английских слов

SPA на Vite + React с интервальными повторениями по системе Лейтнера.
621 слово, весь интерфейс на русском, тёмная тема, mobile-first.
Работает офлайн и ставится на домашний экран iPhone как отдельное приложение.

## Как открыть на телефоне

Собранная версия лежит в `vocab-trainer/docs` — это готовый сайт для GitHub Pages.
Включается один раз в настройках репозитория:

**Settings → Pages → Source: «Deploy from a branch» → Branch:
`claude/english-vocab-leitner-app-7spcoj`, папка `/docs` → Save.**

Через 1-2 минуты приложение будет по адресу
<https://pth5bfv5mz-hub.github.io/Dmitriy/>. Открыть в Safari на iPhone →
«Поделиться» → «На экран «Домой»».

После изменений в коде сборку надо обновить:

```bash
cd vocab-trainer
npm run build:pages   # пересобирает docs/
git add docs && git commit -m "Обновить сборку" && git push
```

## Запуск

```bash
cd vocab-trainer
npm install
npm run dev      # разработка, http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное локально
```

Проверка логики без браузера (33 проверки: интервалы, сбор раунда, статистика,
импорт старых данных, симуляция 40 дней занятий):

```bash
node scripts/selftest.mjs
```

## Как устроено хранение

Всё лежит в `localStorage` того браузера, где открыто приложение. Никаких
сетевых вызовов и внешних API — прогресс не уходит с устройства. Запись
синхронная, сразу при каждом ответе (данные лёгкие, дебаунс не нужен).

| Ключ             | Содержимое                                                             |
| ---------------- | ---------------------------------------------------------------------- |
| `vocab-progress` | `{ [en]: { box: 0..5, due: timestamp } }`                              |
| `vocab-stats`    | `{ byDate: { "YYYY-MM-DD": { sessions, right, wrong } }, totalSessions, totalRight, totalWrong }` |
| `vocab-settings` | `{ direction: "en-ru" \| "ru-en" }`                                    |
| `vocab-seed`     | отметка, что разовый импорт старых данных уже выполнен                  |

При чтении данные нормализуются: битые записи отбрасываются, номер ящика
обрезается до 0..5, старые ключи дат вида `2026-8-16` приводятся к
`2026-08-16`. Если `localStorage` недоступен (приватный режим Safari), приложение
не падает — переходит на память вкладки и показывает предупреждение на главной.

**Перенос старого прогресса.** При самом первом запуске, если хранилище пустое,
подставляется снимок из прошлой версии (15 слов + статистика за 2026-08-16) —
см. `LEGACY_SNAPSHOT` в `src/lib/storage.js`. Повторно импорт не срабатывает
никогда, в том числе после кнопки «Сбросить всё».

**Резервная копия.** Экран «Статистика» → «Управление данными»: скопировать
прогресс в JSON и вставить его на другом устройстве. Пригодится при смене
телефона — localStorage не переезжает сам.

## Логика повторений

6 ящиков, интервалы до следующего показа в днях: `[0, 1, 3, 7, 16, 30]`.

- **«знал»** → ящик +1 (максимум 5), `due = сейчас + интервал нового ящика`;
- **«не знал»** → ящик 0, `due = сейчас`, слово возвращается в очередь этой же
  сессии (через несколько карточек, а не сразу следующим экраном);
- **раунд** = просроченные слова (`due <= сейчас`, сначала из младших ящиков)
  + до 15 новых + добор случайными изученными словами, если карточек меньше 20.

Раундов в день сколько угодно, никаких суточных блокировок.

Константы собраны в начале `src/lib/leitner.js`:

| Константа       | Значение | Зачем                                                        |
| --------------- | -------- | ------------------------------------------------------------ |
| `NEW_PER_ROUND` | 15       | сколько новых слов открывать за раунд                        |
| `MIN_ROUND`     | 20       | ниже этого добираем случайные изученные слова                |
| `MAX_ROUND`     | 40       | потолок раунда, чтобы сессия на телефоне не была марафоном   |
| `BACKLOG_PAUSE` | 60       | при таком долге повторений новые слова временно не открываем |

Про `BACKLOG_PAUSE`: в требовании сказано «**до** 15 новых слов». Если брать
ровно 15 всегда, при одном раунде в день долг повторений растёт быстрее, чем
разгребается — на симуляции 40 дней получалось ~500 просроченных слов, и почти
ничего не доходило до ящиков 4-5. С паузой словарь проходится целиком, а долг
держится около нуля. Разгребли повторения — новые слова снова пошли.

## Офлайн и установка на iPhone

`public/sw.js` кеширует оболочку приложения и все файлы сборки: после первой
загрузки приложение открывается без сети. Навигация идёт network-first с откатом
на кеш, остальное — cache-first (файлы сборки версионируются хешем в имени).
Прогресс service worker не трогает, он в localStorage.

Установка: открыть ссылку в **Safari** → «Поделиться» → «На экран «Домой»».
Приложение запустится без адресной строки, в своём окне.

## Деплой (бесплатно)

Во всех вариантах сначала собираем:

```bash
cd vocab-trainer
npm install
npm run build      # результат в vocab-trainer/dist
```

### Вариант 1 — Netlify Drop (быстрее всего, без аккаунта и без git)

1. Открыть <https://app.netlify.com/drop>.
2. Перетащить туда **папку `dist`** целиком.
3. Через несколько секунд появится ссылка вида
   `https://random-name-123.netlify.app` — её и открывать на телефоне.

Ссылка постоянная. Чтобы обновить приложение позже, надо пересобрать и
перетащить `dist` заново (или подключить git, см. вариант 2).

### Вариант 2 — Netlify из репозитория (обновляется само)

1. Запушить проект на GitHub.
2. <https://app.netlify.com> → **Add new site → Import an existing project** →
   выбрать репозиторий.
3. Настройки сборки:
   - **Base directory**: `vocab-trainer`
   - **Build command**: `npm run build`
   - **Publish directory**: `vocab-trainer/dist`
4. Deploy. Дальше каждый push в ветку пересобирает сайт сам.

### Вариант 3 — Vercel

1. <https://vercel.com/new> → импортировать репозиторий.
2. Настройки:
   - **Root Directory**: `vocab-trainer`
   - Framework Preset: **Vite** (команда сборки и `dist` подставятся сами)
3. Deploy → ссылка вида `https://имя-проекта.vercel.app`.

Или из терминала:

```bash
npm i -g vercel
cd vocab-trainer
vercel --prod
```

### Важно про HTTPS

Service worker работает только по HTTPS (или на `localhost`). Netlify и Vercel
дают HTTPS сразу, так что офлайн-режим и установка на домашний экран заработают
без дополнительной настройки.
